
# AI-Powered Portfolio — Backend

A personal portfolio backend built with **Java, Spring Boot, and PostgreSQL**, designed to expose RESTful APIs and support AI-powered interactions. The project focuses on clean architecture, maintainability, and efficient data access while providing a foundation for future enhancements.

## Tech Stack

- **Language:** Java
- **Framework:** Spring Boot
- **Backend:** Spring Web, Spring Data JPA
- **ORM:** Hibernate
- **Database:** PostgreSQL
- **Build Tool:** Maven
- **Deployment:** Render
- **Database Hosting:** Supabase

## Architecture

The application follows a layered architecture that separates API handling, business logic, and data persistence.

- **Controller Layer:** Handles incoming HTTP requests and API responses.
- **Service Layer:** Encapsulates business logic and application workflows.
- **Repository Layer:** Manages database interactions using Spring Data JPA.
- **Database Layer:** Stores and manages application data in PostgreSQL.

## Key Engineering Focus

- RESTful API design and backend development.
- Separation of concerns through layered architecture.
- Relational database integration using JPA and Hibernate.
- Environment-specific deployment and cloud hosting.
- Extensibility for AI-powered features and performance optimization.
